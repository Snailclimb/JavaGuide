## ⭐️ Gợi ý project RAG thực chiến

Giới thiệu một project thực chiến mã nguồn mở của tác giả, xây trên Spring Boot 4.0 + Java 21 + Spring AI + PostgreSQL + pgvector + RustFS + Redis, hiện thực các chức năng cốt lõi như phân tích CV thông minh, phỏng vấn mô phỏng bằng AI, truy vấn RAG trên knowledge base. Rất phù hợp làm project học tập và project ghi vào CV, ngưỡng học tương đối thấp.
